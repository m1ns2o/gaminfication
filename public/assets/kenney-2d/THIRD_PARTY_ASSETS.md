# Third-party 2D assets

The PNG files in this directory are selected, self-hosted assets from Kenney.
They are distributed under Creative Commons CC0 1.0.

## Sources

- `campus/` — Kenney, [Isometric Tiles Buildings](https://kenney.nl/assets/isometric-tiles-buildings), version 1.0, CC0 1.0.
- `eco/grass.png`, `eco/pond.png` — Kenney, [Isometric Tiles Landscape](https://kenney.nl/assets/isometric-tiles-landscape), version 1.0, CC0 1.0.
- `eco/pine.png`, `eco/tree.png`, `eco/plant.png` — Kenney, [Foliage Pack](https://kenney.nl/assets/foliage-pack), version 1.0, CC0 1.0.
- `space/planet.png` — Kenney, [Planets](https://kenney.nl/assets/planets), version 1.0, CC0 1.0. The source PNG was resized to 320 × 320 for the web bundle.
- `space/ship.png`, `space/satellite.png`, `space/station.png` — Kenney, [Simple Space](https://kenney.nl/assets/simple-space), version 1.0, CC0 1.0.
- `tokens/` — Kenney, [Toon Characters](https://kenney.nl/assets/toon-characters), version 1.0, CC0 1.0.
